# 测试矩阵模板

测试时复制对应表格到测试记录，逐格填写。判据速查见文末；缺陷类型见 [defects.md](defects.md)。

## 路径矩阵

每条路径 = 一次真实对话推演。触发对象用具体示例（书名/内容/对话），验证重点写可检查的断言。

| # | 路径 | 触发对象 | 验证重点 | 结果 |
|:--|:--|:--|:--|:--|
| 1 | 主流程全链路 | （具体示例） | ①→②→③ 逐关落位，交付物齐全 | |
| 2 | 分支线入口 | | 分支入口识别正确，不串线 | |
| 3 | 首条消息带阶段词 | "「X 怎么做」" | 仍从 ① 起，不跳步 | |
| 4 | 模板直跳 | | 直跳模式独立可用 | |
| 5 | 导航·回退 | | 回退到上一关概要，不重跑 | |
| 6 | 导航·重做 | | 重做覆盖旧交付物 | |
| 7 | 导航·跳关 | | 跳关注明跳过内容 | |
| 8 | 导航·退出 | | 停止+总结，不追问 | |
| 9 | 状态对账 | 复用已测对象 | 检测已产出 → 认领不重复 | |
| 10 | 边界·无用户档案/无记忆 | | 兜底话术干净，不假装 | |
| 11 | 边界·歧义对象 | | 列候选让用户确认 | |
| 12 | 时效/外部信息 | | 联网核验 + 标注来源 | |
| 13 | 触发·能力边界 | 边界外请求（无关话题/能力外） | 该拒的拒，不硬接不编造 | |
| 14 | 失败·降级 | 异常输入/资源缺失 | 优雅降级，不报错裸奔；重做/连发结果一致（幂等） | |
| 15 | 组合级·联动 | 与相邻 skill 同用 | 无越权/循环调用/成本复利 | |
| 16 | 基线对照 | 同任务裸 prompt | skill 加持优于零成本方案 | |

> 行数按目标 skill 实际分支增减：每分支至少 1 条，每类导航动词至少 1 条，主流程必 1 条。

## 笛卡尔积矩阵

输入类型 × 模式 × 状态 的必测组合。以下为常见高险组合，按目标 skill 补增。

| 输入类型 | ×模式 | ×状态 | 必测场景 | 实测结果 |
|:--|:--|:--|:--|:--|
| 首条消息带阶段词 | 任意线 | 入口 | 是否跳前置闸门 | |
| 提前产出交付物 | 任意线 | 流程中 | 是否复读 | |
| 模糊表达 | 菜单匹配 | 流程中 | 是否误触发其他通道 | |
| 主动导航词 | 任意线 | 流程中 | 是否有规则响应 | |
| 中断后回来 | 任意线 | 任意 | 状态是否保留/认领 | |
| 越权请求 | 模式 A 请求模式 B | 流程中 | 拒后引导话术是否干净 | |
| 连发输入 | 任意模式 | — | 是否刷屏/前缀堆叠 | |
| 异常输入 | 任意模式 | 任意 | 降级是否优雅、失败反馈是否清晰 | |
| 重复操作 | 任意模式 | 流程中 | 幂等：重做/连发结果一致 | |
| 轻量问法（只想要简短答案） | 完整流程模式 | 入口 | 是否被推入完整流程（无轻量出口）——description 承诺多场景但只有一条完整流程时必测 | |
